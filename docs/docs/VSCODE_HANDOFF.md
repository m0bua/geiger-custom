# Handoff для VS Code

## Мета

Створити нову прошивку для Mira Safety Geiger-2 / HiStand-сумісного приладу на STM32L051C8T6. Користувач повідомив, що стокова прошивка більше не завантажується. Причину збою ще не встановлено; у цьому експорті немає нової спроби прошивки.

Відомі апаратні орієнтири: трубка SBM-20-1, робоча напруга близько 400 V; зовнішня SPI-пам’ять близько 1 MiB; EEPROM-дамп 2 KiB заповнений нулями. Це не замінює перевірки маркування компонентів і сигналів перед керуванням HV.

## Поточний етап

- Погоджені основні екрани, розміри двох шрифтів і частина взаємодій.
- Погоджена загальна ідея журналу з подіями та записами встановлення часу.
- Зібрані результати реверс-аналізу EN 4.1.17, індекс звернень до ресурсів, карта пам’яті та карта старих шрифтів.
- Збережено останній рендер п’яти екранів.
- STM32-прошивка збирається; на платі підтверджені RGB LED, кнопки та керування підсвіткою.
- LCD-контролер, кольорова заливка через DMA, RGB LED, кнопки, підсвітка та PWM яскравість перевірені на платі. Історія та поточний стан: [LCD_BRINGUP](LCD_BRINGUP.md); пояснення знайденої помилки ініціалізації: [LCD_STOCK_GUIDE](LCD_STOCK_GUIDE.md).
- Ще немає лічильного входу, вимірів батареї/сонячного входу, SPI-журналу, EEPROM-конфігурації або застосунку.

## Рекомендований порядок реалізації

1. Зафіксувати решту карти плати: лічильний вхід, динамік, ліхтарик, SPI та HV.
2. Визначити безпечний стан керування/зворотного зв’язку HV. Не писати у зовнішню SPI до підтвердження мікросхеми та геометрії стирання.
3. Перевірити імпульсний вхід на відомому джерелі; реалізувати лічильник, CPS/CPM/CPH та конфігурований коефіцієнт дози.
4. Виміряти ADC-канали батареї й сонячного входу та скласти калібрувальні криві.
5. Реалізувати EEPROM налаштувань і версіоновані журнальні структури у SPI.
6. Додати шрифти й екранні стани, звіряючи результат із renders/.
7. Вибрати транспорт застосунку, після чого зробити його на чистому JavaScript і відкрити всі налаштування.

Перші тести виконувати з вимкненим або контрольованим HV, доки GPIO керування та вимірювання не будуть підтверджені. Не підключати вимірювальні прилади до високовольтної частини без належного рейтингу та процедури.
