# Застосунок і параметри

## Застосунок

- Бажана реалізація — чистий JavaScript без залежностей, якщо транспорт зв’язку це дозволить.
- Застосунок відкриває всі налаштування; на приладі показується лише основна підмножина.
- Протокол зв’язку та транспорт (USB, BLE чи інший) ще не вибрано. Не закладати API конкретного браузера до вибору транспорту й цільової платформи.
- Налаштування мають читатися, змінюватися, зберігатися на пристрої та повертатися застосунку з версією схеми.

## Таблиця одиниць

Для кожної фізичної величини окремо активуються варіанти часу:

| Тип | Можливі варіанти |
|---|---|
| Sv | H, M, S — наприклад µSv/h, µSv/min, µSv/s |
| CNT | CPH, CPM, CPS |
| R | H, M, S — наприклад µR/h, µR/min, µR/s |

Для кожної з трьох груп застосунок дозволяє ввімкнути 1–9 варіантів. Лише вибрані одиниці з’являються в меню приладу. Остаточні скорочення мають бути узгоджені з шириною малого шрифту.

## Параметри, які користувач хоче мати в застосунку

- коефіцієнт калібрування імпульси → дозова величина;
- вибір доступних одиниць для Sv, CNT, R;
- синхронізація часу з UNIX-часом;
- глибина журналу: кількість сирих лічильних подій і глибина хвилин/годин/днів; повзунки збільшують один ресурс за рахунок інших;
- інтервал усереднення AVG/MAX;
- кількість значущих цифр, приховування початкового нуля й авто-масштаб одиниць;
- призначення кнопок, зокрема команда вимкнення: лише екран / датчик / повне вимкнення;
- режим індикації кліків: вимкнено / лише при активному екрані / завжди;
- яскравість і автоматичний режим;
- таймаут екрана 0–90 с;
- спільний профіль `TONE` для кліків і звукового аларму;
- пороги/калібрування рівня Li-ion і сонячного входу, щойно їхні виміри будуть встановлені.

## Меню на приладі

Локальне меню показує основні опції: одиниці, яскравість, таймаут, індикацію імпульсів, звукові пороги та скидання налаштувань. Застосунок лишається повною панеллю конфігурації.

Скидання параметрів не повинно створювати запис у журналі вимірів. Питання очищення журналу — окрема команда/політика; її поведінку ще не узгоджено.

## Майбутній вигляд

На майбутній реліз залишити редагування теми в застосунку: чорний фон, світло-сірий текст і зелений акцент із невеликим червоним відхилом як початкові кольори. Зараз це статика, а не активне налаштування.
