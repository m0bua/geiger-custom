# Відкриті питання

Цей список містить питання, що лишилися після перевірки поточного прототипу.
Погоджені, але ще не реалізовані функції описано окремо в
[PRODUCT_AND_UI](PRODUCT_AND_UI.md) та [LOG_AND_STORAGE](LOG_AND_STORAGE.md).

## Узгоджений порядок наступних функцій

1. Ліва кнопка на головному екрані.
2. Ліва кнопка на екрані дози.
3. Налаштування часу.
4. Статистика: графіки та збереження, розбивка на логи; деталі — у [PRODUCT_AND_UI](PRODUCT_AND_UI.md) і [LOG_AND_STORAGE](LOG_AND_STORAGE.md).
5. Використання SPI-пам’яті для логів, окрім EEPROM.
6. Оптимізація споживання.
7. JS-застосунок і протокол обміну з приладом.

| Пріоритет | Питання | Що потрібно зробити |
|---|---|---|
| Критичний | Перевірка керування HV | Налаштування `HV` керує PA5 за стоковими on/off-переходами; електричне навантаження PA5, зв’язок із HV та безпечна поведінка на reset/bootloader потребують перевірки на платі. Не трактувати PA5 як підтверджений HV enable. |
| Високий | Калібрування дози | Зіставити показ швидкості з контрольним джерелом і підтвердити коефіцієнт для встановленої трубки/напруги. Поточний екран використовує алгоритм, відновлений зі стоку. |
| Високий | Перевірка імпульсів | Вхід PB6/EXTI6 працює в прототипі; користувач спостерігав близько 20–26 CPM. Потрібне довше порівняння з незалежним лічильником. |
| Високий | Батарея | ADC2 відображається за формулою зі стокового аналізу. Перевірити напругу на PA2 та відповідність показаного відсотка реальному рівню заряду мультиметром; стокова шкала сама по собі не підтверджує фізичне калібрування. |
| Високий | Сонячний вхід | ADC9 реагує на вхід; показ використовує стокове `raw / 31`. Перевірити дільник і калібрування за напругою. |
| Високий | SPI NOR | Підтвердити точну мікросхему, JEDEC ID та геометрію сторінки/стирання перед реалізацією журналу. |
| Середній | Повна карта GPIO | Встановити фізичні сигнали динаміка, ліхтарика та невідомих ліній. Відрізняти кодові кандидати від підтверджених доріжок. |
| Середній | LCD | Пікселі, DMA й кнопкову навігацію перевірено. Уточнити точну модель контролера, RGB/BGR-порядок та орієнтацію панелі. Див. [LCD_AND_DISPLAY](LCD_AND_DISPLAY.md) і [LCD_STOCK_GUIDE](LCD_STOCK_GUIDE.md). |
| Середній | Дані між перезапусками | Визначити джерело часу, ідентифікатор запуску, відновлення подій і збереження накопиченої дози. Поточна доза скидається при перезавантаженні. |
| Середній | Журнал | Узгоджено типи потоків і два режими сховища; визначити точний формат, глибину, точність поклікового інтервалу, поведінку після раптового вимкнення й межі EEPROM/SPI NOR. Див. [LOG_AND_STORAGE](LOG_AND_STORAGE.md). |
| Середній | Застосунок | Вибрати транспорт, платформу та версіонований протокол зв’язку. |
| Низький | Локальні опції | Вирішити, чи потрібні експорт/очищення журналу, блокування кнопок та налаштування звукового попередження. |

## Не робити висновок завчасно

Сирі значення ADC та збіг з формулами стоку не підтверджують фізичну напругу.
GPIO, який сток перемикає під час ввімкнення, не можна вважати HV enable без
перевірки плати. Наявність робочої підсвітки не доводить справність цифрового
живлення LCD.
