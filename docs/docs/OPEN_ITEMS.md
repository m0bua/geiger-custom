# Відкриті питання перед реалізацією

| Пріоритет | Питання | Що треба встановити |
|---|---|---|
| Критичний | HV enable, регулювання і feedback | GPIO/PWM/ADC ланцюг, стани reset/bootloader, safe-start і межі SBM-20-1 |
| Високий | Лічильний імпульс | GPIO, полярність, ширина, фільтрація, максимальна частота, безпечний interrupt/timer mode |
| Високий | Батарея Li-ion | ADC-канал, дільник, зарядний стан, таблиця напруга→%, гістерезис та точність |
| Високий | Сонячний вхід | Чи вимірюється напруга/струм/лише факт заряджання; значення показаного відсотка та калібрування |
| Високий | Коефіцієнт SBM-20-1 | Знайти заводську константу й перевірити її контрольним джерелом; узгодити одиниці та орієнтир HV 400 V |
| Високий | SPI-пам’ять | Точна мікросхема, JEDEC ID, erase/page geometry, write endurance; підтвердити старий 1 MiB дамп |
| Середній | Повна карта GPIO | RGB-кандидати PA0/PA1/PA6; кнопкові кандидати PA4/PB9 зі стокового HEX; полярність і прив’язка лівої/правої кнопки ще не підтверджені; решта сигналів невідома |
| Середній | Дисплей | Контролер, SPI/паралельний інтерфейс, init, орієнтація, частота оновлення, backlight pin |
| Середній | Журнал і глибина | RAM-кеш сирих подій, тривалість, хвилинні/годинні/денні агрегати, резерв на раптове вимкнення |
| Середній | Boot sequence | Як зберігається ідентифікатор запуску без окремої reset-події журналу |
| Середній | Час | UNIX у UTC, відображення часової зони, повторна синхронізація та відновлення подій між перезавантаженнями |
| Середній | Застосунок | Транспорт/платформа, формат повідомлень, версія протоколу, відновлення після переривання зв’язку |
| Низький | Статистичні межі | Точне число хвилин/годин/днів і правило перетворення агрегацій між ними |
| Низький | Додаткові локальні опції | Чи додавати очищення журналу, блокування кнопок, низький заряд, експорт логів |

## Можливі додаткові налаштування

Кандидати для наступного обговорення: попередження про низький заряд, mute/lock кнопок, експорт журналу, очищення журналу з підтвердженням, поведінка дисплея при першому натисканні після таймауту. Це пропозиції, не затверджені вимоги.
