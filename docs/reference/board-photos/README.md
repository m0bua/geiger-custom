# Фото плати

Це фото, передані для аналізу плати. Зображення перекодовано зі збереженням змісту та оригінальних назв; за назвами не встановлюється, який бік або вузол зображений.

Кількість файлів: 12. Два більші кадри зменшено до 2200 px по довгій стороні; решту фото перекодовано з нижчою JPEG-якістю для економії місця. Для інтерпретації кожне фото треба звіряти з маркуванням компонентів і схемою, якщо вона буде надана.
