# Фото плати

Це вихідні фото, передані для аналізу плати. Файли не редагувалися. Назви збережено з оригінальних завантажень; за назвами не встановлюється, який бік або вузол зображений.

Кількість файлів: 10. Для інтерпретації кожне фото треба звіряти з маркуванням компонентів і схемою, якщо вона буде надана.
