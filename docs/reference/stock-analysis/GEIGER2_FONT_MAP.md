### Кодування растра

- Кожен рядок збережений як little-endian 16-бітне слово; піксель `x=0` відповідає біту 15, наступні пікселі йдуть ліворуч направо.
- Відступ між гліфами: 36 B для 11×18, 20 B для 7×10, 16 B для 5×8.
- У стовпці «Растр» один рядок рисунка відділений `/`; `#` — засвічений піксель, `.` — фон.
- Адреса — початок даних гліфа; індекс таблиці починається з 00.

## Що карта підтверджує і що ні

- У 11×18 таблиці є 40 слотів, індекси відповідають кодам `0x20–0x47`. Окрім цифр і пунктуації, видимі літери — `h`, `µ`, `S`, `v`, `C`, `P`, `M`, `R`, `N`, `F`, `E`.
- 7×10 містить 31 видимий гліф; 5×8 містить 12. Це не повний ASCII набір.
- У самих таблицях, що вказані активними дескрипторами, повного A–Z алфавіту не видно. Якщо повну англійську абетку додавали в окремий блок чи в іншу версію HEX, потрібен той HEX для доповнення карти.
- Це карта даних файлу 0415, а не підтвердження фактичного відображення кожного гліфа на пристрої.
