# VA / power measurements

Матеріали вимірювань від 03.11.2026 для аналізу живлення, HV, екрана, сну та ADC акумулятора.

> Уточнення умов: заміри напруги виконувалися без HV, але з активними процесором і екраном. Напруга вимірювалася безпосередньо на клемах акумулятора. При ввімкненні HV помітного додаткового просідання напруги не спостерігалося.

## Що є в каталогах

| Каталог | Умова вимірювання |
|---|---|
| `hvoff` | HV вимкнений |
| `scope` | Заміри струму осцилографом |
| `screen1` | Екран увімкнений, яскравість 1% |
| `screen100` | Екран увімкнений, яскравість 100% |
| `sleep` | Сон із увімкненим HV |
| `voltages` | Нова серія перевірки напруги та RAW ADC |
| `voltages-fail` | Попередня серія з нестабільною/суперечливою відповідністю напруги та RAW |
| `wake` | Процесор не спить через підключений USB |

Фото в `VA-prohos` стиснуто до приблизно 2400 px по довгій стороні з JPEG quality 80. Фото в `board-photos` також перекодовано зі збереженням оригінальних назв; два більші кадри зменшено до 2200 px.

## Дані, перенесені з фото

### ADC акумулятора

- Вимірювання акумулятора виконується 12-бітним ADC STM32 на `ADC2 / PA2`.
- При активному пристрої, зокрема при увімкненому екрані, перевірка батареї запускається приблизно раз на `30 с` (`BATTERY_ACTIVE_SAMPLE_INTERVAL_MS = 30000`). У тривалому idle-режимі інтервал — близько `30 хв`, а для критичного рівня знову `30 с`.
- На фото [`voltages-fail/20261103_091803.jpg`](voltages-fail/20261103_091803.jpg) видно: зовнішня напруга `4.5513 V`, а на debug-екрані — `BATT 100% / RAW 2040`.
- На тому ж екрані: `BATT START 100% / RAW 2214`, `WAKE 079%`, `SLEEP 021%`, uptime `0D 00:06:15`. `BATT START` — стартове значення, тому його не слід трактувати як вимір у той самий момент.
- Окремо зафіксовано під час старого тесту: при `4.6 V` показувався приблизно `RAW 2078`. Цю точку не змішуємо з новою серією.

### Важливий висновок про шкалу відсотків

Поточна прошивка використовує фіксовану шкалу приблизно `RAW 1300 = 0%` і `RAW 2000 = 100%`. Значення вище `RAW 2000` обрізаються до 100%.

За виміряними точками `4.55–4.6 V -> RAW 2040–2078` поріг 100% відповідає приблизно `4.43–4.46 V`, якщо екстраполювати лінійну залежність. Для однієї Li-ion/LiPo комірки це не є коректною шкалою: нормальна верхня напруга повністю зарядженої комірки — близько `4.2 V`.

Отже, `BATT 100%` зараз означає лише «RAW досяг програмного порогу», а не «акумулятор заряджений до фізично правильних 4.2 V». Калібрувати відсоток треба за реальною напругою на клемах акумулятора та фактичним коефіцієнтом дільника, а не за тестовою точкою 4.6 V.

> Якщо `4.6 V` подавали безпосередньо на однокомірковий Li-ion/LiPo акумулятор, це небезпечна перенапруга. Таку точку слід трактувати тільки як тест лабораторного входу/вимірювального ланцюга; для самого акумулятора потрібен ліміт заряджання не вище передбаченого схемою, зазвичай 4.2 V.

### Нижня межа за поведінкою екрана

Під час розряду спостерігалося таке:

- на `2.65 V` екран ще працює адекватно;
- приблизно після `2.6 V` екран починає помітно тьмяніти;
- нижче цього рівня екран стає практично непридатним для роботи/фотографування.

Практична рекомендація — взяти `2.7 V` як мінімум для нормальної роботи дисплея та початок захисної реакції. Це консервативніше за фактичну межу `2.6 V` і залишає запас на просідання. Для прошивки бажано додати гістерезис: вимикати/затемнювати нижче `2.7 V`, а повертати нормальний режим лише після підняття напруги вище приблизно `2.8 V`.

### Споживання та режими

- `hvoff`, `screen1`, `screen100`, `sleep` і `wake` — порівняльні серії, що дозволяють відокремити вплив HV, яскравості екрана, сну та USB.
- Фото з осцилографа показують імпульсний характер споживання, тому одиночне значення мультиметра не обов’язково дорівнює піковому або середньому струму.
- На фото [`voltages-fail/20261103_091803.jpg`](voltages-fail/20261103_091803.jpg) мультиметр показує `4.5513 V` і приблизно `5387.3 µA` (`5.3873 mA`). Це значення стосується конкретного режиму цього кадру, а не універсального струму сну.

## Обмеження вимірювань

Фото — це підтвердження окремих точок, але не машинозчитуваний лог: частина кадрів знята під кутом, із відблисками або недостатньою різкістю. Для фінального калібрування слід повторити серію контрольованим джерелом і записати для кожної точки: напругу на вході, напругу на PA2, RAW ADC, струм, режим пристрою та час після переходу в режим.
