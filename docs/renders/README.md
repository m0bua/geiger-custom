# Рендери

preview.html — автономна браузерна сторінка з усіма п’ятьма макетами.
geiger-display-pages-redrawn.html — вихідний фінальний рендер із попереднього етапу.
screens/ — ті самі SVG екрани окремими файлами в порядку: рівень, доза, час, налаштування, статистика.

Координати рендера відповідають фізичній матриці 160×80 px. Масштабувати лише для перегляду; не змінювати геометрію джерела.
