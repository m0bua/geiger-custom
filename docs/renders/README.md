# Рендери екранів пристрою

Нумерація відповідає ієрархії екранів. Рендери відтворюють матрицю 160×80, геометрію та bitmap-гліфи з прошивки (`src/board_stm32l051.c`, `src/font_small.c`, `src/font_large.c`). Значення наведені як приклади стану.

Попередній посібник: [USER_MANUAL_DRAFT.md](../USER_MANUAL_DRAFT.md).

## 1. Рівень

- `screens/1.0.1-rate-blue-cnt.svg` — синій rate warm-up із µSv/h, CNT-прогресом і статусами S/L.
- `screens/1.0.2-rate-green-cpm.svg` — варіант із зеленим рівнем і CPM.

### 1.1. Налаштування

- `screens/1.2.1-settings-simple.svg` — список налаштувань із вибраним пунктом UNIT; курсор і рядок виділені зеленим.
- `screens/1.2.2-settings-many-options.svg` — редагування LED BRIGHT; назва залишається білою, курсор і вибране значення AUTO зелені. ALARM STOP відображений білим.
- `screens/1.2.3-settings-actions.svg` — нижні рядки меню: RESET виділений червоним, POWER OFF і REBOOT жовті.

## 2. Доза

- `screens/2-dose.svg` — сумарна доза в µSv із другим рядком CNT та статусами S/L.

### 2.1. Графіки та журнали

- `screens/2.1-graph-90s.svg` — live rate graph за 90 секунд із білим роздільником; дані умовні.

- `screens/2.2-graph-days.svg` — денний графік: буферний запис перший, 6-піксельні стовпчики з проміжком 1 піксель, вибраний запис зелений; статистика опущена нижче, стрілки тривалості немає.
- `screens/2.3-graph-alerts.svg` — графік `< ALRT >` із вибраним записом; MAX вище червоного порога показаний червоним.
