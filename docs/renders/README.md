# Рендери екранів пристрою

Нумерація відповідає переходам між екранами: екран рівня — `1`, його підменю — `1.1` і `1.2`; доза — `2`, графіки з екрана дози — `2.1` і `2.2`. Рендери відтворюють матрицю 160×80, геометрію та bitmap-гліфи з прошивки (`src/board_stm32l051.c`, `src/font_small.c`, `src/font_large.c`). Значення наведені як приклади стану.

## 1. Рівень

- `screens/1.0-rate-blue-cpm.svg` — базовий екран рівня із CPM.
- `screens/1.0.1-rate-blue-cnt.svg` — варіант із CNT-прогресбаром.
- `screens/1.0.2-rate-green-cpm.svg` — варіант із зеленим рівнем і CPM.

### 1.1. Час

- `screens/1.1-time.svg` — час, дата й аптайм.

### 1.2. Налаштування

- `screens/1.2.1-settings-simple.svg` — перша сторінка, виділено простий перемикач USE-SPI.
- `screens/1.2.2-settings-many-options.svg` — друга сторінка, виділено LED BRIGHT із дев’ятьма варіантами; редагування ще не ввімкнене.

## 2. Доза

- `screens/2-dose.svg` — сумарна доза з вимкненим другим рядком.

### 2.1. Графік за 90 секунд

- `screens/2.1-graph-90s.svg` — короткий графік CPM; приклад історії синтетичний.

### 2.2. Денний графік

- `screens/2.2-graph-days.svg` — 21 день; приклад записів синтетичний, вибраний день має дату в заголовку.
