Manual

      

        Readings and data
        
    
          
  • Overview: shows the current rate, accumulated dose for today, device date/time and uptime, solar level, and battery level. The rate and dose units follow the device's UNIT and prefix settings. Hover over the rate chart to read a plotted value; it keeps the latest three minutes.
    • 
          
  • Logs: inspect minute, hour, day, and alert records. Choose a range, load records in groups of ten, and export the records currently loaded as CSV. See the detailed Logs guide below for coverage, live records, and storage.
    • 
          
  • Settings: read and change options supported by the connected firmware. Values that depend on another setting may be disabled. The Show checkboxes control which options appear in the device menu; setting and visibility changes are applied immediately. The device clock can be synchronized to the computer's current local time. POWER OFF is always shown and has no visibility checkbox.
    • 
          
  • Debug: inspect device time and clock source, uptime, pulse count, power readings, physical log counts, storage state, memory sizes, and SPI identification. Sections are in one table and can be collapsed independently.
    • 
          
  • Without a connection: Overview, Logs, and Debug show clearly marked illustrative zero data. Settings use factory defaults and can be changed for preview, but preview changes are not saved and reset after reloading the page. Options unsupported by the connected firmware remain visible but disabled.
    • 
        

        
Logs

        
The Logs page reads the same history used by the device's log graphs. Select a log type and range, then press Load. You can choose the type and range before connecting; switching tabs keeps each loaded view. Load more adds the next ten records. The current record may refresh while the page is open.

        
    
          
  • MINUTES: one record per minute, with dose, average rate, maximum rate, and coverage.
    • 
          
  • HOURS: one record per hour with the same values. The newest unfinished hour is assembled from minute data.
    • 
          
  • DAYS: one record per day. The newest unfinished day is assembled from smaller intervals.
    • 
          
  • ALERTS: one record per alert episode, showing duration, dose, average rate, and maximum rate.
    • 
        

        
Dose is accumulated detector counts converted to the selected UNIT and prefix. In CNT mode, dose is shown as CNT and rates as CPM. Average rate uses the record's actual covered time; missing time is not treated as zero activity.

        
Coverage applies to minute, hour, and day records. It shows the represented percentage and seconds, followed by the state: full, partial, or live. A partial record's dose and average describe only the time actually measured. A live record is the current in-progress interval and can change until it closes. Alert records show duration instead of coverage.

        
The Fill selector changes the shaded bar behind table values. For MINUTES, HOURS, and DAYS it can compare Dose, Average, Maximum, or Coverage; for ALERTS it can compare Duration, Dose, Average, or Maximum. The shading is scaled against the largest value in the currently loaded records. Metric text is highlighted when it reaches a warning or red level.

        
Range presets are Latest, All, 5, 10, 50, and Custom. Latest loads up to 60 minutes, 24 hours, 30 days, or 5 alerts, depending on the selected type. Numeric presets select that many newest records. All loads the entire available history in groups of ten. For a numeric preset, Load more adds ten more records. Custom loads a calendar interval; the left date/time bound must be newer than the right bound. Minute ranges use minute precision and hour ranges use hour precision. Calendar ranges require a valid device clock.

        
Export saves only the records currently loaded for the selected log type; it does not fetch the rest of the selected range. Load the full range you need first. The CSV includes timestamp, type, dose and units, average and maximum rate, covered seconds, coverage percentage, and record status.

        
Storage: EEPROM and SPI each keep minute, hour, day, and alert records, but SPI holds much more history. The device writes new records only to the selected LOG MEMORY. Switching between EEPROM and SPI starts a fresh active log set; records are not migrated. Selecting SPI erases SPI contents, including stock assets, and clears the old EEPROM log set. LOG MEMORY=OFF pauses new log writes while retaining existing records. DEBUG counts physically stored records; a current in-memory graph point may not yet be included.

      

      

        Settings reference
        
Settings are listed below in device-menu order. In the app, supported changes are sent to the device immediately; unsupported settings remain visible but disabled. Show controls visibility in the device menu, where POWER OFF is always shown. Demo changes are temporary and return to defaults when the page is reloaded.

        
On the device, long Right activates a setting. Most settings with up to three choices change immediately. LOG MEMORY and settings with more choices open a separate list: short Left/Right selects an option, long Right saves, and long Left cancels. Each entry into the settings list starts at the first visible item.

        
For rate indications and alarms, YELLOW covers the yellow and red levels, starting at 0.4 µSv/h; RED starts above 0.9 µSv/h. CUSTOM uses RATE CUSTOM. Rate-based triggers wait until the initial measurement window is ready. INVISIBLE suppresses indications and alarms; SEARCH keeps the screen on and flashes the LED on pulses.

        
    
          
  • DOSE PERIOD — UPTIME / DAY / TOTAL: shows accumulated dose since this run started, for the current calendar day, or for the lifetime total. Changing the period resets DOSE ROW 2 to TIME for UPTIME, or to the first alternative unit for DAY and TOTAL (CNT when UNIT is Sv).
    • 
          
  • LED — OFF / ON / ALWAYS / YELLOW / RED / CUSTOM: controls pulse flashes. ON flashes while the display is on; ALWAYS also flashes while it is off. The remaining modes flash at the chosen rate level.
    • 
          
  • CLICKS — OFF / ON / ALWAYS / YELLOW / RED / CUSTOM: controls speaker clicks on pulses using the same trigger choices as LED.
    • 
          
  • RATE SCREEN — OFF / YELLOW / RED / CUSTOM: wakes and keeps the display on while the chosen rate condition is active. Acknowledging the alarm lets the display time out.
    • 
          
  • RATE LIGHT — OFF / YELLOW / RED / CUSTOM: flashes the flashlight twice per second at the chosen rate level.
    • 
          
  • RATE SOUND — OFF / YELLOW / RED / CUSTOM: plays a siren at the chosen rate level.
    • 
          
  • RATE CUSTOM: selects a custom rate threshold of 0.3, 0.4, 0.5, 0.7, 0.9, 1, 2, 5, or 10 µSv/h. The device menu omits the unit.
    • 
          
  • DOSE SCREEN — OFF / YELLOW / RED / CUSTOM: wakes and keeps the display on at the chosen accumulated-dose threshold. Acknowledging the alarm lets the display time out.
    • 
          
  • DOSE LIGHT — OFF / YELLOW / RED / CUSTOM: flashes the flashlight twice per second at the chosen accumulated-dose threshold.
    • 
          
  • DOSE SOUND — OFF / YELLOW / RED / CUSTOM: plays a siren at the chosen accumulated-dose threshold.
    • 
          
  • DOSE CUSTOM: selects an accumulated-dose threshold of 5, 7, 10, 30, 50, 100, 500, or 1000 µSv. For the three DOSE alarm settings, YELLOW and RED are the dose that would accumulate at 0.4 or 0.9 µSv/h over the measured time in the selected period. The device menu omits the unit.
    • 
          
  • ALARM STOP — CLEAR / BUTTON: controls when the siren stops. CLEAR stops it when its condition clears; BUTTON keeps it sounding until a button is pressed. During an active alarm, the first button press acknowledges the alarm, silences the siren, stops alarm flashlight flashes, and lets the screen time out without navigating. It can trigger again after the conditions clear and recur.
    • 
          
  • RATE ROW 2: for Sv/R, show CPM, CPS, OFF, or the opposite radiation unit. For CNT, show Sv, R, OFF, or CPS.
    • 
          
  • DOSE ROW 2: show another unit, another dose period, TIME, CPM, or OFF. The current unit and current period are unavailable choices.
    • 
          
  • LED TIME — AUTO / 1 / 3 / 5 / 10 / 25 / 50 / 80 / 100 ms: sets the pulse duration. AUTO follows SOLAR, from 5 ms in darkness to 100 ms at 30% solar and above. With the screen off, SOLAR is sampled once per minute while an LED AUTO setting is selected.
    • 
          
  • LED BRIGHT — AUTO / 1 / 3 / 5 / 10 / 25 / 50 / 80 / 100%: sets LED PWM brightness. AUTO follows SOLAR. LED TIME and LED BRIGHT are independent.
    • 
          
  • SCREEN BRIGHT — AUTO / 1% / 3% / 5% / 10% / 25% / 50% / 80% / 100%: AUTO uses an average of solar readings and changes brightness gradually, with a 1% minimum.
    • 
          
  • SCREEN TIMER — 1 / 5 / 10 / 30 / 60 / 90 seconds: inactivity time before the display turns off. SEARCH keeps the display on; INVISIBLE uses a one-second timeout.
    • 
          
  • TONE — STOCK / CLASSIC: selects the sound character for pulse clicks and the siren.
    • 
          
  • LONG PRESS — 300 / 500 / 700 / 900 / 1100 / 1300 ms: sets the time required to trigger a long button press.
    • 
          
  • UNIT — Sv / CNT / R: selects the unit for both main screens and the app's Overview and Logs. R follows the device's stock-compatible ×100 scaling of Sv. Changing UNIT resets the rate and dose prefixes to their defaults for that unit.
    • 
          
  • RATE PREFIX: for Sv/R, choose m, µ, n, or AUTO; for CNT, choose CPM or CPS.
    • 
          
  • DOSE PREFIX: for Sv/R, choose m, µ, n, or AUTO. It is unavailable for CNT.
    • 
          
  • LEAD ZERO — SHOW / HIDE: controls the zero before a decimal fraction.
    • 
          
  • HV — ON / OFF: OFF disables detector counting and freezes dose updates. Turning it ON restarts the rate warm-up from zero.
    • 
          
  • LOG MEMORY — EEPROM / SPI / OFF: selects where new logs are stored. OFF pauses logging. The device does not fall back to the other memory if the selected storage fails. See storage details below before switching.
    • 
          
  • RESET — SETTINGS / LOGS / OLD LOGS / EEPROM / SPI / ALL: selects a reset action; see the effects below. The device executes the selected action on long Right without another on-device confirmation. The app asks for confirmation.
    • 
          
  • POWER OFF: shuts down the device.
    • 
          
  • REBOOT: restarts the device.
    • 
        


        
Log storage and reset actions

        
MIN records close at minute boundaries. HOUR and DAY records are calculated from shorter-period records and saved at their boundaries. Incomplete intervals retain their measured coverage. ALERT records start at a yellow or red rate and close when it clears; episodes are split at 4,096 seconds. Each log is a ring that overwrites its oldest records when full.

        
    
          
  • EEPROM: up to 62 MIN, 25 HOUR, 50 DAY, and 30 ALERT records.
    • 
          
  • SPI NOR (1 MiB): up to 30,082 MIN, 9,802 HOUR, 16,562 DAY, and 24,650 ALERT records in separate rings. Actual capacity can be lower when records occupy partially filled sectors.
    • 
          
  • Switching storage: switching from EEPROM to SPI erases the entire SPI chip, including stock assets, and clears EEPROM logs. Switching from SPI to EEPROM clears EEPROM logs; SPI records remain in inactive storage. Records are not migrated. OFF retains stored records; returning from OFF to the same storage resumes its log set if the storage remains valid, while switching to the other storage starts a fresh set. Changing storage resets the in-progress buffers.
    • 
          
  • RESET SETTINGS: restores settings defaults.
    • 
          
  • RESET LOGS: clears EEPROM logs and erases the entire SPI chip, including stock assets.
    • 
          
  • RESET OLD LOGS: clears inactive storage: EEPROM when SPI is selected, SPI when EEPROM is selected, or both when LOG MEMORY is OFF. Clearing SPI erases the entire chip, including stock assets.
    • 
          
  • RESET EEPROM: erases internal EEPROM, including settings and dose checkpoints. RESET SPI erases the entire SPI chip. RESET ALL erases both memories.
    • 
        

        
Successful reset actions restart the device. Actions that clear SPI require the SPI chip to be accessible. Erasing stock assets affects a return to stock firmware; keep a backup if needed.


        
Factory defaults: LED ALWAYS; CLICKS and alarm outputs OFF; both brightness settings AUTO; SCREEN TIMER 10 seconds; TONE STOCK; LEAD ZERO SHOW; UNIT Sv; both prefixes µ; RATE ROW 2 CPM; DOSE PERIOD DAY with DOSE ROW 2 CNT; LONG PRESS 900 ms; HV ON; LOG MEMORY EEPROM; ALARM STOP CLEAR. RATE CUSTOM defaults to 0.9 µSv/h and DOSE CUSTOM to 5 µSv. RATE CUSTOM, DOSE CUSTOM, LONG PRESS, HV, LOG MEMORY, DOSE SCREEN, DOSE LIGHT, DOSE SOUND, ALARM STOP, TONE, LEAD ZERO, RATE PREFIX, DOSE PREFIX, RESET, and REBOOT are hidden from the device menu by default and can be shown from the app.

      

      

        Device manual
        

        
This guide describes the device display and its two buttons. The illustrations are representative screen layouts; values shown in them are examples.

        

        
Button gestures

        
    
          
  • Short press: press and release before the configured long-press threshold.
    • 
          
  • Long press: hold until the device recognizes it. The threshold is configurable in Settings → LONG PRESS.
    • 
          
  • Left button: changes indication mode on Rate/Dose; in menus it moves backward or cancels.
    • 
          
  • Right button: switches the main screen; in menus it moves forward or confirms.
    • 
        

        
At startup, the LED lights white for about one second. On Rate, short Left cycles NORMAL → SEARCH → INVISIBLE. If SEARCH has been active for 10 seconds, the next press returns directly to NORMAL. NORMAL has no mode letter; SEARCH shows a green S, INVISIBLE a red I, and the yellow L appears only while the flashlight is manually on. Short Right switches between Rate and Dose. Long Left toggles the flashlight on either main screen.

        
Long Right on Rate opens the last-used extra screen (Settings is first after startup). The extra screens are Settings and Debug; short Left/Right switches between them. On Settings, long Right opens the settings list; long Left leaves the list, and another long Left returns to the main screen. In Debug, long Right advances through its pages. Long Right on Dose opens Graphs. Holding Left for 3 seconds forces a return to the Rate screen, including from a slow or unresponsive graph. While any alarm is active, the first button press is consumed: it silences the siren, stops alarm light flashing, and acknowledges the alarm. The screen may then time out even if the trigger remains; the alarm can activate again only after the trigger clears and occurs again. If the display is asleep, a button press normally only wakes it. In INVISIBLE, short Left exits the mode and wakes the display in the same press.

        


        

        
1 · Level screen

        
The large value is the current rate in the selected UNIT and RATE PREFIX. The top row shows device time when set, otherwise hours and minutes since startup, plus solar input and battery status. RATE ROW 2 selects the smaller second row. During startup, the rate is blue and the progress bar fills to 30 CNT; the estimate starts at 23 CPM and settles toward the measured rate. With HV off, Rate shows red DISABLED; counting and rate/dose updates stop, and turning HV back on restarts the rate warm-up from zero. Rate colors and alarms follow their configured thresholds.

        
SEARCH keeps the display on and flashes the LED on detector pulses. INVISIBLE suppresses detector indications and alarms and turns the display off after one second; measurements continue. Short Left exits Invisible even while the display is asleep.

        

          
          
        

        


        

        
1.1 - Settings

        
Long Right opens the settings list at its first visible item. Short Left/Right moves the highlight. Long Right activates the highlighted item. Options with up to three choices change immediately, except LOG MEMORY. For LOG MEMORY and options with more choices, a separate screen lists all values down the left column and then the right; short Left/Right moves the selection, long Right saves, and long Left cancels. RESET runs the selected action on long Right without an additional on-device confirmation; the app still asks before executing a reset. The list includes indication and alarm behavior, tone, brightness and screen timeout, units and prefixes, secondary rows, dose period, log memory, long-press timing, reset actions, Power Off, and Reboot. RESET and REBOOT are hidden by default and can be shown from the app. Some items depend on the selected unit. Set the device clock on the app's Settings page.

        

          
          
          
        

        


        

        
1.2 - Debug

        
The extra-screen group contains Settings and Debug. Short Left/Right switches between them. Debug has three pages: time/date, uptime, total pulse count, RTC status and clock source, plus detected SPI capacity and JEDEC ID; voltage and power readings; physical log counts and store status. Long Right advances through Debug pages. SPI is probed when Debug opens. The app presents these diagnostics together in one table.

        


        

        
2 · Dose

        
Shows accumulated dose in the selected UNIT and DOSE PREFIX for the DOSE PERIOD: UPTIME (this run), DAY (the current calendar day), or TOTAL (lifetime). DOSE ROW 2 can show another unit or period, TIME, CPM, or OFF; changing the period selects TIME for UPTIME or the first alternative unit for DAY and TOTAL. Short Left changes the shared NORMAL/SEARCH/INVISIBLE indication mode; short Right returns to Rate; long Left toggles the flashlight; long Right opens Graphs.

        
        


        

        
2.1 · Graphs

        
Long Right from Dose opens Graphs. Short Left/Right cycles SEC, MIN, HOUR, DAY, and ALRT. SEC shows live rate history; long Right cycles its 10/30/60/90-second window. For a log graph, long Right enters column selection; short Left/Right moves cyclically through columns. The selected column is green and its date/time, dose, MAX, AVG, and covered duration are shown. Long Left leaves column selection; another long Left returns to Dose. Holding Left for 3 seconds forces a return to the Rate screen.

        
Log graphs show the current in-progress interval first, followed by older records from that log. The current hour is assembled from minute records, and the current day from hour records; older columns come from their own stored log. The history limits are 60 minute records, 24 hourly records, 50 daily records, and 50 alerts; at most 13 columns are visible on screen at once. With no column selected, MIN and HOUR summarize the visible window; DAY summarizes retained daily records. Partial records contribute only their measured time. EEPROM and SPI both store all four log types, with much greater history available in SPI mode. The app's Logs tab lists records and coverage details.

        Command-line flashing (STM32CubeProgrammer)
        
Replace COM with the device's serial port. Run the commands from the directory containing the firmware image.

        
Start application firmware

        
STM32_Programmer_CLI -c port=COM br=115200 p=even rts=high dtr=low

        
Enter the ROM bootloader

        
STM32_Programmer_CLI -c port=COM br=115200 p=even rts=high dtr=high

        
Flash a HEX image

        
STM32_Programmer_CLI -c port=COM br=115200 p=even rts=low dtr=high -w rom.hex -v

        
Flash a BIN image

        
STM32_Programmer_CLI -c port=COM br=115200 p=even rts=low dtr=low -w rom.bin -v

Known limitations

        
    
          
  • Only firmware images on the compatibility checksum list receive the normal application HELLO startup check. Unlisted project builds are started without that check.
    •

    • 
          
  • SPI dump requires compatible running firmware with SPI logging enabled and a ready SPI memory chip.

Enable SPI logging?

      
This will erase the assets stored on the SPI chip. After the assets are erased, you will not be able to return this device to stock firmware. Continue only if you accept this permanent change.
