Manual

      

        
Start here

        
    
          
  1. Serve the repository locally with python -m http.server 8000, then open http://localhost:8000/app/.
    2. 
          
  2. Connect the device with Connect. Opening the serial port can restart the device; the app waits for it to answer.
    3. 
          
  3. Use the tabs to view readings, browse logs, edit supported settings, inspect diagnostics, or manage firmware.
    4. 
        

      

      

        
Firmware and backups

        
Before flashing, use Firmware → Dumps → FLASH and save the downloaded backup. The local-build button flashes the latest existing .pio/build/geiger2/firmware.bin; it does not compile the firmware.

        
Manual flashing accepts validated STM32 .hex and .bin images. Read the image status and keep Verify after programming enabled. Reboot and dump controls are in the collapsible sections below Flash firmware.

      

      

        
Readings and data

        
    
          
  • Overview: current rate, dose today, solar and battery readings, device clock, and recent rate chart.
    • 
          
  • Logs: browse day, minute, hour, and alert records when available. Load older pages as needed.
    • 
          
  • Settings: read and change settings supported by the connected firmware.
    • 
          
  • Debug: inspect uptime, counters, clock, memory, log counts, and raw voltage readings.
    • 
        

      

      
Web Serial requires a supported browser and a secure context such as localhost or HTTPS.

Known limitations

        
    
          
  • Only firmware images on the compatibility checksum list receive the normal application HELLO startup check. Unlisted project builds are started without that check.
    • 
          
  • Battery and solar percentages, dose calibration, RTC behavior after full power loss, and SPI logging reliability still need physical verification.
    • 
          
  • SPI dump requires compatible running firmware with SPI logging enabled and a ready SPI memory chip.
    • 
        

      

      
See project open items for the current hardware and firmware verification list.
