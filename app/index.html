Manual

      

        Readings and data
        
    
          
  • Overview: shows the current rate, accumulated dose for today, device date/time and uptime, solar level, and battery level. The rate and dose units follow the device's UNIT and prefix settings. Hover over the rate chart to read a plotted value; it keeps the latest three minutes.
    • 
          
  • Logs: browse minute, hour, day, and alert records. The range selector offers Latest, All, 5, 10, 50, and Custom; Latest is the default and loads the latest hour of minutes, day of hours, or month of days. Custom shows newer-to-older date/time bounds; minute bounds have minute precision and hour bounds have hour precision. Load fetches the selection in batches of five. Export saves the records already loaded in the table as CSV.
    • 
          
  • Settings: read and change options supported by the connected firmware. Values that depend on another setting may be disabled. The Show checkboxes control which options appear in the device menu; setting and visibility changes are applied immediately. The device clock can be synchronized to the computer's current local time. POWER OFF is always shown and has no visibility checkbox.
    • 
          
  • Debug: inspect device time and clock source, uptime, pulse count, power readings, physical log counts, storage state, memory sizes, and SPI identification. Sections are in one table and can be collapsed independently.
    • 
          
  • Without a connection: Overview, Logs, and Debug show clearly marked illustrative zero data. Settings use factory defaults and can be changed for preview, but preview changes are not saved and reset after reloading the page. Options unsupported by the connected firmware remain visible but disabled.
    • 
        

      

      

        Settings reference
        
In the app, supported setting changes are sent to the device immediately. On the device, options with more than three choices require long Right to enter editing, short Left/Right to choose a value, and long Right to save; long Left cancels. Unsupported settings remain visible but disabled in the app. The Show checkbox controls whether a setting appears in the device menu; POWER OFF is always shown.


        
Indication and alarms

        
    
          
  • LED — OFF / ON / ALWAYS / YELLOW / RED / CUSTOM: controls pulse flashes. ON flashes only while the display is on; ALWAYS also flashes with the display off. YELLOW and RED flash at the matching rate threshold. CUSTOM uses RATE CUSTOM.
    • 
          
  • CLICKS — OFF / ON / ALWAYS / YELLOW / RED / CUSTOM: same trigger choices as LED, using the speaker for pulse clicks.
    • 
          
  • RATE SCREEN / RATE LIGHT / RATE SOUND — OFF / YELLOW / RED / CUSTOM: independently choose which rate levels activate the display, flashlight, or sound alarm. YELLOW starts at 0.4 µSv/h; RED starts above 0.9 µSv/h. CUSTOM uses RATE CUSTOM. The display stays on until the rate falls below its trigger. The flashlight alarm flashes twice per second; the sound alarm uses a siren.
    • 
          
  • RATE CUSTOM: custom rate threshold: 0.3, 0.4, 0.5, 0.7, 0.9, 1, 2, 5, or 10 µSv/h. The device menu omits the unit to save space.
    • 
          
  • DOSE SCREEN / DOSE LIGHT / DOSE SOUND — OFF / YELLOW / RED / CUSTOM: independently choose which accumulated-dose levels activate the display, flashlight, or sound alarm. YELLOW and RED mean the dose that would accumulate at 0.4 or 0.9 µSv/h over the selected DOSE PERIOD. The display stays on until the dose falls below its trigger. CUSTOM uses DOSE CUSTOM.
    • 
          
  • DOSE CUSTOM: accumulated-dose threshold of 5, 7, 10, 30, 50, 100, 500, or 1000 µSv. The device menu omits the unit to save space.
    • 
          
  • ALARM STOP — CLEAR / BUTTON: controls how the sound alarm is acknowledged. CLEAR lets the siren stop when its triggering condition ends. BUTTON keeps the siren latched after that condition ends until a button is pressed. A button press during any active alarm always silences the alarm outputs and is consumed; it does not navigate.
    • 
          
  • TONE — STOCK / CLASSIC: selects the sound character for pulse clicks and the sound alarm. STOCK preserves the current stock-style sound; CLASSIC uses a short dry click.
    • 
        


        
Display

        
    
          
  • LED BRIGHT: AUTO or 1%, 3%, 5%, 10%, 25%, 50%, 80%, 100%. AUTO follows solar level, with a 5% minimum and full brightness by 30% solar.
    • 
          
  • SCREEN BRIGHT: AUTO or the same fixed percentages. AUTO follows solar level and has a 1% minimum.
    • 
          
  • SCREEN TIMER — 1 / 5 / 10 / 30 / 60 / 90 seconds: inactivity time before the display turns off. SEARCH keeps the display on; INVISIBLE uses a one-second timeout.
    • 
          
  • LEAD ZERO — SHOW / HIDE: controls the zero before a decimal fraction. HIDE removes that leading zero while preserving the fractional digits.
    • 
        


        
Units and secondary rows

        
    
          
  • UNIT — Sv / CNT / R: selects radiation dose/rate units, pulse counts, or the device's stock-compatible R display convention (R uses the firmware's ×100 scaling; it is not a universal Sv-to-R conversion). The choice affects both main screens and the app's Overview and Logs.
    • 
          
  • RATE PREFIX: for Sv/R, choose m, µ, n, or AUTO. In CNT mode, choose CPM or CPS.
    • 
          
  • DOSE PREFIX: for Sv/R, choose m, µ, n, or AUTO. It is unavailable in CNT mode.
    • 
          
  • RATE ROW 2: for Sv/R, show CPM, CPS, OFF, or the opposite radiation unit. For CNT, show Sv, R, OFF, or CPS. A value identical to the main unit is disabled in the app.
    • 
          
  • DOSE ROW 2: show another unit, another dose period, TIME, CPM, or OFF. The current unit and current period are disabled choices. The default is TIME for DOSE PERIOD=UPTIME and CNT otherwise.
    • 
          
  • DOSE PERIOD — UPTIME / DAY / TOTAL: selects the interval used for the accumulated dose: since this run started, since the current calendar day began, or the lifetime total.
    • 
        


        
Device and storage

        
    
          
  • LONG PRESS — 300 / 500 / 700 / 900 / 1100 / 1300 ms: sets how long a button must be held to trigger a long press.
    • 
          
  • HV — ON / OFF: OFF disables detector counting and freezes rate and dose updates. Turning it ON restarts the rate warm-up from zero.
    • 
          
  • LOG MEMORY — EEPROM / SPI / OFF: EEPROM stores daily records; SPI adds minute and hour records. OFF stops new log writes without erasing existing logs. Enabling SPI erases SPI assets and prevents returning to stock firmware; read the app's confirmation before proceeding.
    • 
          
  • RESET: SETTINGS / LOGS / OLD LOGS / EEPROM / SPI / ALL: SETTINGS restores defaults; LOGS clears EEPROM and SPI log data; OLD LOGS clears logs in inactive storage (EEPROM when LOG MEMORY is SPI, SPI when it is EEPROM, and both when LOG MEMORY is OFF); EEPROM erases internal EEPROM, including settings; SPI erases the SPI chip, including stock assets; ALL erases both memories. Destructive choices restart the device.
    • 
          
  • POWER OFF: shuts the device down.
    • 
          
  • REBOOT: restarts the device.
    • 
        


        
Factory defaults: LED ALWAYS; CLICKS and alarm outputs OFF; both brightness settings AUTO; SCREEN TIMER 10 seconds; TONE STOCK; LEAD ZERO SHOW; UNIT Sv; both prefixes µ; RATE ROW 2 CPM; DOSE PERIOD DAY with DOSE ROW 2 CNT; LONG PRESS 900 ms; HV ON; LOG MEMORY EEPROM; ALARM STOP CLEAR. RATE CUSTOM defaults to 0.9 µSv/h and DOSE CUSTOM to 5 µSv. RATE CUSTOM, DOSE CUSTOM, LONG PRESS, HV, LOG MEMORY, DOSE SCREEN, DOSE LIGHT, DOSE SOUND, ALARM STOP, TONE, LEAD ZERO, RATE PREFIX, DOSE PREFIX, RESET, and REBOOT are hidden from the device menu by default and can be shown from the app.

      

      

        Device manual
        

        
This guide describes the device display and its two buttons. The illustrations are representative screen layouts; values shown in them are examples.

        

        
Button gestures

        
    
          
  • Short press: press and release before the configured long-press threshold.
    • 
          
  • Long press: hold until the device recognizes it. The threshold is configurable in Settings → LONG PRESS.
    • 
          
  • Left button: changes indication mode on Rate/Dose; in menus it moves backward or cancels.
    • 
          
  • Right button: switches the main screen; in menus it moves forward or confirms.
    • 
        

        
At startup, the LED lights white for about one second. On Rate, short Left cycles NORMAL → SEARCH → INVISIBLE. If SEARCH has been active for 10 seconds, the next press returns directly to NORMAL. NORMAL has no mode letter; SEARCH shows a green S, INVISIBLE a red I, and the yellow L appears only while the flashlight is manually on. Short Right switches between Rate and Dose. Long Left toggles the flashlight on either main screen.

        
Long Right on Rate opens the last-used extra screen (Settings is first after startup). The extra screens are Settings and Debug; short Left/Right switches between them. On Settings, long Right opens the settings list; long Left leaves the list, and another long Left returns to the main screen. In Debug, long Right advances through its pages. Long Right on Dose opens Graphs. Holding Left for 3 seconds forces a return to the Rate screen, including from a slow or unresponsive graph. While any alarm is active, the first button press is consumed: it silences the siren, stops alarm light flashing, and acknowledges the alarm. The screen may then time out even if the trigger remains; the alarm can activate again only after the trigger clears and occurs again. If the display is asleep, a button press normally only wakes it. In INVISIBLE, short Left exits the mode and wakes the display in the same press.

        


        

        
1 · Level screen

        
The large value is the current rate in the selected UNIT and RATE PREFIX. The top row shows device time when set, otherwise hours and minutes since startup, plus solar input and battery status. RATE ROW 2 selects the smaller second row. During startup, the rate is blue and the progress bar fills to 30 CNT; the estimate starts at 23 CPM and settles toward the measured rate. With HV off, Rate shows red DISABLED; counting and rate/dose updates stop, and turning HV back on restarts the rate warm-up from zero. Rate colors and alarms follow their configured thresholds.

        
SEARCH keeps the display on and flashes the LED on detector pulses. INVISIBLE suppresses detector indications and alarms and turns the display off after one second; measurements continue. Short Left exits Invisible even while the display is asleep.

        

          
          
        

        


        

        
1.1 - Settings

        
Long Right opens the settings list. Short Left/Right moves the highlight. Long Right activates the highlighted item. Options with up to three choices change immediately. For options with more choices, long Right enters value editing; short Left/Right cycles values, long Right saves, and long Left cancels. RESET runs the selected action on long Right without an additional on-device confirmation; the app still asks before executing a reset. The list includes indication and alarm behavior, tone, brightness and screen timeout, units and prefixes, secondary rows, dose period, log memory, long-press timing, reset actions, Power Off, and Reboot. RESET and REBOOT are hidden by default and can be shown from the app. Some items depend on the selected unit. Set the device clock on the app's Settings page.

        

          
          
          
        

        


        

        
1.2 - Debug

        
The extra-screen group contains Settings and Debug. Short Left/Right switches between them. Debug has three pages: time/date, uptime, total pulse count, RTC status and clock source, plus detected SPI capacity and JEDEC ID; voltage and power readings; physical log counts and store status. Long Right advances through Debug pages. SPI is probed when Debug opens. The app presents these diagnostics together in one table.

        


        

        
2 · Dose

        
Shows accumulated dose in the selected UNIT and DOSE PREFIX for the DOSE PERIOD: UPTIME (this run), DAY (the current calendar day), or TOTAL (lifetime). DOSE ROW 2 can show another unit or period, TIME, CPM, or OFF; the default is TIME for UPTIME and CNT otherwise. Short Left changes the shared NORMAL/SEARCH/INVISIBLE indication mode; short Right returns to Rate; long Left toggles the flashlight; long Right opens Graphs.

        
        


        

        
2.1 · Graphs

        
Long Right from Dose opens Graphs. Short Left/Right cycles SEC, MIN, HOUR, DAY, and ALRT. SEC shows live rate history; long Right cycles its 10/30/60/90-second window. For a log graph, long Right enters column selection; short Left/Right moves cyclically through columns. The selected column is green and its date/time and dose, MAX, AVG, and coverage duration are shown. Long Left leaves column selection; another long Left returns to Dose. Holding Left for 3 seconds forces a return to the Rate screen.

        
Log graphs show the newest temporary buffer entry first, followed by stored records. They use six-pixel bars with one-pixel gaps, about 15 bars visible at once. The device graph limits are 60 minutes, 24 hours, 50 days, and up to 50 alerts. With no column selected, MIN and HOUR summarize their displayed window; DAY summarizes available daily records. MIN/HOUR recording requires LOG MEMORY=SPI; EEPROM stores daily records. The app's Logs tab lists stored records and coverage details.

        Command-line flashing (STM32CubeProgrammer)
        
Replace COM with the device's serial port. Run the commands from the directory containing the firmware image.

        
Start application firmware

        
STM32_Programmer_CLI -c port=COM br=115200 p=even rts=high dtr=low

        
Enter the ROM bootloader

        
STM32_Programmer_CLI -c port=COM br=115200 p=even rts=high dtr=high

        
Flash a HEX image

        
STM32_Programmer_CLI -c port=COM br=115200 p=even rts=low dtr=high -w rom.hex -v

        
Flash a BIN image

        
STM32_Programmer_CLI -c port=COM br=115200 p=even rts=low dtr=low -w rom.bin -v

Known issues

        
    
          
  • After using the app, disconnect and reconnect the USB cable before using another tool. Otherwise, commands may behave unpredictably.
    • 
          
  • Estimated battery life is currently 5–8 days. Power optimization is still in progress.

Known limitations

        
    
          
  • Only firmware images on the compatibility checksum list receive the normal application HELLO startup check. Unlisted project builds are started without that check.
    • 
          
  • Battery and solar percentages, dose calibration, RTC behavior after full power loss, and SPI logging reliability still need physical verification.
    • 
          
  • SPI dump requires compatible running firmware with SPI logging enabled and a ready SPI memory chip.

Enable SPI logging?

      
This will erase the assets stored on the SPI chip. After the assets are erased, you will not be able to return this device to stock firmware. Continue only if you accept this permanent change.
